# 代码语言识别测试

三种语言各一段，用来验证围栏代码块里的**语法着色**。
只看"语言标签显示了"是不够的——标签来自装饰层，着色来自语法解析，
两者是独立的链路，前者正常而后者失效时，界面上很像是"没问题"。

JavaScript：

```js
// 行注释
const 甲 = "字符串"
function 乙(n) { return n * 42 }
```

Python：

```python
# 注释
def 丙(x):
    return x ** 2
```

Rust：

```rust
// 注释
fn main() {
    let s = "文本";
    println!("{}", s);
}
```
